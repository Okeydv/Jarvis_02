# Джарвис — голосовой ИИ-ассистент для Windows

Ассистент в духе J.A.R.V.I.S. для Windows 10/11: понимает голос и текст, отвечает голосом и
управляет компьютером через вызов инструментов (function calling). Всё бесплатно: распознавание
и синтез речи работают офлайн, языковую модель можно запускать локально.

- **Три языковые модели на выбор** (переключатель в окне и в `config.yaml`):
  - **Ollama** — локально, по умолчанию `qwen3:8b`, без интернета;
  - **GigaChat** — бесплатный режим Freemium для физлиц;
  - **Gemini** — бесплатный ключ Google AI Studio.
- **Голос:** распознавание — Vosk (`vosk-model-small-ru`), синтез — Silero TTS v4 (голос `aidar`).
- **Режим «Джарвис»:** постоянно слушает и выполняет фразы, начинающиеся со слова «Джарвис».
- **Горячая клавиша `Ctrl+Alt+J`** — начать слушать, даже если окно свёрнуто.
- **Управление ПК:** приложения, сайты, папки, громкость, медиа, ввод текста, горячие клавиши,
  скриншоты, таймеры, заметки, блокировка/сон/выключение, PowerShell (выключен по умолчанию).
- **Безопасность:** опасные действия выполняются только после подтверждения кнопкой «Да».

## Быстрый старт

1. **Установите Python 3.10 или новее** с [python.org](https://www.python.org/downloads/).
   В установщике отметьте **«Add python.exe to PATH»**.
2. **Скачайте проект**: кнопка *Code → Download ZIP* (и распакуйте) или `git clone`.
3. **Запустите `install.bat`**. Он создаст окружение `.venv`, установит зависимости
   (PyTorch ставится CPU-версией), скачает модели Vosk и Silero и сертификат для GigaChat,
   а также создаст файл `.env`. Нужно около 2 ГБ места и интернет.
4. **Подготовьте языковую модель** (достаточно одной):
   - **Ollama (по умолчанию).** Установите [Ollama](https://ollama.com/download) и в терминале выполните
     `ollama pull qwen3:8b`. Модели нужно около 6 ГБ памяти; видеокарта ускоряет работу, но не обязательна.
   - **GigaChat.** Получите ключ авторизации в [личном кабинете](https://developers.sber.ru/studio)
     (проект GigaChat API → «Настройки API» → «Получить ключ») и впишите в `.env`:
     `GIGACHAT_CREDENTIALS=ваш_ключ`.
   - **Gemini.** Получите бесплатный ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
     и впишите в `.env`: `GEMINI_API_KEY=ваш_ключ`. Если Gemini недоступен в вашем регионе,
     укажите прокси в `config.yaml` → `gemini.proxy` или включите VPN.
5. **Запустите `run.bat`.** Пока загружаются голосовые модели, в окне горит «Загрузка…»;
   текстом можно писать сразу.

Ручная установка (вместо `install.bat`):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python download_models.py
copy .env.example .env
python main.py
```

## Как пользоваться

| Действие | Как |
|---|---|
| Написать команду | Поле ввода внизу, **Enter** или «Отправить» |
| Сказать одну команду | Кнопка **«Микрофон»** или **Ctrl+Alt+J** (работает и при свёрнутом окне), после сигнала говорите |
| Режим «Джарвис» | Включите переключатель и говорите: «**Джарвис**, открой браузер». Можно сказать просто «Джарвис», дождаться сигнала и произнести команду |
| Остановить речь и ответ | Кнопка **«Стоп»**, клавиша **Esc** или голосом: «стоп», «хватит», «Джарвис, замолчи» |
| Перебить | В режиме «Джарвис» скажите новую команду со словом «Джарвис», пока он говорит |
| Выключить озвучку | Переключатель «Озвучивать ответы» |
| Сменить модель | Переключатель **Ollama / GigaChat / Gemini** (выбор запоминается в `config.yaml`) |
| Начать заново | «Новый диалог»: история очищается |

Индикатор состояния: **Жду** (серый), **Слушаю** (синий), **Думаю** (жёлтый),
**Выполняю** (фиолетовый), **Говорю** (зелёный). Справа, в **журнале действий**, видно время,
вызванный инструмент, его аргументы и результат.

Примеры команд:

- «Джарвис, открой браузер» / «открой телеграм» / «закрой блокнот»
- «Найди в интернете рецепт борща» / «Открой ютуб»
- «Сделай громкость 30» / «Выключи звук» / «Следующий трек» / «Пауза»
- «Открой загрузки» / «Сделай скриншот» / «Какая загрузка процессора?»
- «Поставь таймер на 10 минут на чай» / «Запиши заметку: купить молоко»
- «Открой блокнот и напиши: привет, мир» / «Нажми ctrl+s»
- «Заблокируй компьютер» / «Выключи компьютер» (спросит подтверждение) / «Отмени выключение»

## Инструменты

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `open_app(name)` | Запуск по алиасу из `config.yaml` («браузер», «блокнот», «калькулятор», «проводник», «телеграм»…), иначе поиск ярлыка в меню «Пуск» (включая приложения Microsoft Store) | — |
| `close_app(name, force)` | Закрывает приложение: сначала как «крестик» (программа сама спросит о сохранении), `force=true` завершает принудительно (psutil) | **да** |
| `open_url(url)` / `web_search(query)` | Сайт или поиск в браузере по умолчанию (только http/https) | — |
| `open_folder(path)` | «Загрузки», «Документы», «Рабочий стол», «Изображения», «Музыка», «Видео», «Корзина», вложенные и полные пути | — |
| `set_volume(level)` / `mute(on)` | Громкость 0–100 и режим «без звука» (pycaw) | — |
| `media(action)` | `play_pause`, `next`, `previous`: медиаклавиши | — |
| `type_text(text)` | Печатает текст в активном окне (русский тоже, независимо от раскладки) | — |
| `hotkey(keys)` | Сочетание клавиш через pyautogui, например `ctrl+c`, `win+d` | **только Alt+F4** |
| `screenshot()` | Снимок всех экранов в «Изображения\Jarvis» | — |
| `system_info()` | Процессор, память, батарея, диск, время работы | — |
| `get_datetime()` | Дата, время, день недели | — |
| `timer(minutes, label)` | Таймер; по окончании — уведомление Windows и голос | — |
| `note(text)` | Дописывает заметку в «Документы\Jarvis\notes.txt» | — |
| `lock_pc()` | Блокировка компьютера | — |
| `sleep_pc()` / `shutdown_pc()` / `restart_pc()` | Сон, выключение, перезагрузка (с задержкой, её можно отменить: `cancel_shutdown()`) | **да** |
| `run_powershell(command)` | Команда PowerShell; **выключен по умолчанию** (`tools.allow_powershell`) | **да, с показом всей команды** |

## Безопасность

- `close_app`, `sleep_pc`, `shutdown_pc`, `restart_pc`, `run_powershell` и `hotkey` с Alt+F4
  выполняются **только после подтверждения** в диалоге с точным описанием действия и кнопками
  «Да» / «Нет». Если ответа нет 20 секунд (`tools.confirm_timeout`), действие отменяется.
  Подтвердить можно только кнопкой, голосом нельзя, чтобы случайная фраза ничего не выключила.
- Проверку делает реестр инструментов до вызова функции, так что обойти её из модели нельзя.
- `run_powershell` выключен по умолчанию, а при включении всегда показывает команду целиком.
- Модель может вызвать только инструменты из списка, неизвестные вызовы отклоняются.
- Ошибка инструмента не роняет программу: её текст возвращается модели, а та сообщает о проблеме.
- `close_app` не трогает системные процессы и сам Джарвис. «Проводник» закрывает только окна,
  а не процесс `explorer.exe`.
- Alt+F4 никогда не отправляется в окно Джарвиса: в диалоге подтверждения видно, какое окно закроется.

## Настройки (`config.yaml`)

Файл подробно прокомментирован. Главное:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `llm.backend` | `ollama` | `ollama` / `gigachat` / `gemini` |
| `llm.max_steps` | `5` | максимум обращений к модели на один запрос |
| `llm.history_messages` | `20` | сколько последних сообщений помнить |
| `ollama.model` | `qwen3:8b` | любая модель Ollama с поддержкой tools |
| `ollama.think` | `false` | размышления qwen3 выключены ради скорости |
| `gigachat.model` | `GigaChat-2` | также `GigaChat-2-Pro`, `GigaChat-2-Max`, `GigaChat-3-Ultra` |
| `gemini.model` | `gemini-flash-latest` | или `gemini-flash-lite-latest` (быстрее, выше лимиты) |
| `gemini.proxy` | пусто | прокси для Gemini, например `http://127.0.0.1:10809` |
| `system_prompt` | характер Джарвиса | системный промпт |
| `voice.vosk_model_path` | `models/vosk-model-small-ru-0.22` | путь к модели Vosk |
| `voice.wake_words` | `джарвис` и варианты | слово-активатор |
| `voice.stop_words` | `стоп`, `хватит`… | слова остановки |
| `tts.speaker` | `aidar` | голос Silero: `aidar`, `baya`, `kseniya`, `xenia`, `eugene` |
| `hotkey` | `ctrl+alt+j` | глобальная горячая клавиша |
| `tools.allow_powershell` | `false` | разрешить `run_powershell` |
| `tools.apps` | список | алиасы приложений |

### Свои приложения

Добавьте строку в `tools.apps`, где ключ — названия через запятую:

```yaml
    "фотошоп, photoshop":
      run: ['start:Photoshop', 'C:\Program Files\Adobe\Adobe Photoshop 2025\Photoshop.exe']
      process: Photoshop.exe
    "мой сайт": https://example.com
```

Варианты запуска: программа из PATH (`notepad.exe`), полный путь (переменные `%APPDATA%` раскрываются),
путь в кавычках с аргументами, URI-протокол (`tg://`, `ms-settings:`), сайт, `start:Имя` (ярлык из меню «Пуск»)
и `@browser` (браузер по умолчанию).

## Решение проблем

Подробный лог: `logs\jarvis.log`. Ошибки и подсказки по исправлению также показываются прямо в чате.

- **«Ollama не запущена»** — запустите приложение Ollama (значок в трее) или `ollama serve`.
- **«Модель qwen3:8b не найдена»** — `ollama pull qwen3:8b`.
- **Ollama отвечает медленно** — при запуске Джарвис заранее загружает модель в память и прогревает её
  (`ollama.preload`), поэтому первые секунды после старта модель может быть занята. Без видеокарты `qwen3:8b`
  работает медленно: попробуйте `qwen3:4b` (`ollama pull qwen3:4b` и `ollama.model` в `config.yaml`)
  или GigaChat/Gemini.
- **GigaChat: ошибка SSL-сертификата** — `python download_models.py --cert` (скачивает корневой
  сертификат НУЦ Минцифры и проверяет его отпечаток) или установите сертификат с
  [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt). Крайний вариант: `gigachat.verify_ssl_certs: false`.
- **GigaChat: 401** — проверьте ключ в `.env` (целиком, без кавычек) и `scope: GIGACHAT_API_PERS`.
- **Gemini: «недоступен в вашем регионе»** — укажите `gemini.proxy` или включите VPN.
- **Gemini: 429** — исчерпан бесплатный лимит, подождите или выберите `gemini-flash-lite-latest`.
- **Русские буквы в пути к папке** (например `C:\Users\Иван\…`) Джарвис обходит сам. Если модель Vosk всё же
  не загружается, перенесите папку с Джарвисом в путь без кириллицы, например `C:\Jarvis`.
- **Нет модели Vosk или микрофона** — `python download_models.py --vosk`, проверьте микрофон в «Параметры →
  Система → Звук» и доступ к нему в «Конфиденциальность → Микрофон». Текстовый режим работает всегда.
- **Плохо слышит «Джарвис»** — говорите чётко, добавьте свой вариант распознавания в `voice.wake_words`
  (что именно распознаётся, видно в строке «Слышу: …» вверху окна).
- **Джарвис реагирует на свой голос** — используйте наушники или уменьшите громкость. Эхо фильтруется,
  но с громкими колонками возможны ложные срабатывания.
- **Горячая клавиша не работает** — сочетание занято другой программой: смените `hotkey` в `config.yaml`.
- **Консоль не нужна** — запускайте `.venv\Scripts\pythonw.exe main.py` (или ярлык на него).

## Как это устроено

```
main.py                   запуск, логирование
config.yaml, .env         настройки и ключи
download_models.py        скачивание моделей Vosk/Silero и сертификата GigaChat
jarvis/
  app.py                  контроллер: связывает окно, агента, голос, горячую клавишу
  ui.py                   окно CustomTkinter и диалог подтверждения
  agent.py                агентский цикл: модель → инструменты → результат → ответ
  llm/                    бэкенды за общим интерфейсом: ollama, gigachat, gemini
  tools.py                инструменты управления ПК с JSON-схемами и подтверждениями
  winapi.py               WinAPI через ctypes: окна, фокус, ввод, папки, уведомления
  stt.py                  распознавание речи Vosk
  tts.py                  синтез Silero и очередь воспроизведения
  text_utils.py           подготовка текста к озвучке, предложения, слово-активатор
  hotkey.py               глобальная горячая клавиша (RegisterHotKey)
tests/                    автотесты (pytest)
```

- **Потоки.** Окно работает в главном потоке. Модель и инструменты, микрофон, синтез, воспроизведение
  и горячая клавиша живут в фоновых потоках и общаются с окном через очередь и `after()`,
  поэтому интерфейс не зависает.
- **Агентский цикл:** не больше 5 обращений к модели на запрос. На последнем шаге модель обязана
  ответить текстом. В контекст идут последние 20 сообщений.
- **Ответ** выводится в чат по мере генерации и озвучивается по предложениям: следующее предложение
  синтезируется, пока играет предыдущее. Перед синтезом текст очищается от markdown и эмодзи,
  числа переводятся в слова с согласованием («двадцать одна минута», «из шестнадцати гигабайт»),
  латиница читается по-русски, текст режется на куски до 800 символов.
- **Vosk и Silero** загружаются один раз при старте. Silero скачивается автоматически, если файла нет.

### Добавить свой инструмент

```python
# jarvis/tools.py
@tool(
    "open_calendar",
    "Открыть календарь Windows.",
    {"date": {"type": "string", "description": "Дата в формате ДД.ММ.ГГГГ (необязательно)"}},
)
def open_calendar(ctx: CallContext, date: str = "") -> str:
    os.startfile("outlookcal:")
    return "Календарь открыт."
```

Опасному действию добавьте `confirm=функция`, возвращающую `Confirmation(...)`: тогда реестр
не вызовет инструмент без нажатия «Да».

### Тесты

```bat
.venv\Scripts\python -m pip install pytest
.venv\Scripts\python -m pytest
```

Тесты не требуют Windows, сети и моделей: они проверяют нормализацию текста, слово-активатор,
реестр инструментов и подтверждения, агентский цикл и перевод истории в форматы Ollama, GigaChat и Gemini.

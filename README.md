# Джарвис — голосовой ИИ-ассистент для Windows

Ассистент в духе J.A.R.V.I.S. для Windows 10/11: понимает голос и текст, отвечает голосом и
управляет компьютером через вызов инструментов (function calling). Распознавание и синтез речи
работают офлайн, языковую модель можно запускать локально или взять бесплатную облачную.

- **Четыре языковые модели на выбор** (переключатель вверху окна):
  - **Ollama** — локально, по умолчанию `qwen3:8b`, без интернета;
  - **Qwen** — облачные модели Alibaba Qwen через [BazaarLink](https://bazaarlink.ai), есть бесплатная
    `qwen/qwen3.7-flash:free`;
  - **GigaChat** — бесплатный режим Freemium для физлиц;
  - **Gemini** — бесплатный ключ Google AI Studio.
- **Голос:** распознавание — Vosk (`vosk-model-small-ru`), синтез — Silero TTS v4 (голос `aidar`).
- **Режим «Джарвис» включён сразу:** ассистент постоянно слушает и выполняет фразы, начинающиеся со
  слова «Джарвис».
- **Горячая клавиша `Ctrl+Alt+J`** — сказать команду, даже если окно свёрнуто.
- **Управление ПК:** приложения и окна, сайты, папки и файлы, громкость, яркость, параметры Windows,
  медиа, ввод текста, сочетания клавиш, буфер обмена, скриншоты, таймеры и напоминания, заметки,
  погода, калькулятор, блокировка/сон/выключение, PowerShell.
- **Программирование:** пишет код в файлы и открывает их в редакторе (VS Code, Notepad++ или Блокнот),
  читает и исправляет код, запускает программы на Python (с подтверждением).
- **Быстрые ответы:** после простых действий («открой браузер», «громче») отвечает сразу, без
  второго обращения к модели.
- **Память:** помнит факты о вас («запомни, что я живу в Казани») и продолжает разговор после
  перезапуска; знает, какое окно сейчас активно, и умеет взять выделенный текст («переведи выделенное»).
- **Сценарии и расписание:** цепочка действий одной фразой («рабочий режим» выполняется мгновенно, без
  обращения к модели) и задачи по времени («каждый будний день в 9:00 — брифинг»).
- **Навыки** в формате [agentskills.io](https://agentskills.io): Джарвис сохраняет то, чему научился, —
  инструкции и, если нужно, скрипт на Python.
- **Зрение:** смотрит на экран через модель со зрением (Qwen, Gemini или Ollama с vision-моделью):
  «что у меня на экране?», «нажми кнопку «Отправить»». Место клика показывается на снимке до подтверждения.
- **Сам предлагает помощь:** замечает, что кончается место на диске, садится батарея, заполнена память
  или программа грузит процессор, и спрашивает, помочь ли. Утренний брифинг и сводка «пока вас не было».
  Без спама: не чаще двух раз в час, тихие часы, режим «Не беспокоить», учится на ваших «нет».
- **HUD:** мини-индикатор поверх всех окон показывает, что делает Джарвис, когда его окно свёрнуто.
- **Откат:** перед перезаписью файла сохраняется прежняя версия — «верни как было».
- **Безопасность:** опасные действия выполняются только после подтверждения кнопкой «Да, выполнить».
- **Диагностика:** проверка микрофона, распознавания, синтеза, модели и инструментов одной кнопкой.

## Быстрый старт

1. **Установите Python 3.10 или новее** с [python.org](https://www.python.org/downloads/).
   В установщике отметьте **«Add python.exe to PATH»**.
2. **Скачайте проект**: кнопка *Code → Download ZIP* (и распакуйте) или `git clone`.
3. **Запустите `install.bat`**. Он создаст окружение `.venv`, установит зависимости
   (PyTorch ставится CPU-версией), скачает модели Vosk и Silero и сертификат для GigaChat,
   а также создаст файл `.env`. Нужно около 2 ГБ места и интернет.
4. **Подготовьте языковую модель** (достаточно одной):
   - **Ollama (по умолчанию).** Установите [Ollama](https://ollama.com/download) и в терминале выполните
     `ollama pull qwen3:8b`. Модели нужно около 6 ГБ памяти; видеокарта ускоряет работу, но не обязательна.
   - **Qwen (BazaarLink).** Зарегистрируйтесь на [bazaarlink.ai](https://bazaarlink.ai), создайте ключ в
     разделе API Keys (вида `sk-bl-…`) и вставьте его в **«Настройки → Модели → Qwen»** — или впишите в
     `.env`: `BAZAARLINK_API_KEY=ваш_ключ`. Затем выберите **Qwen** вверху окна.
   - **GigaChat.** Получите ключ авторизации в [личном кабинете](https://developers.sber.ru/studio)
     (проект GigaChat API → «Настройки API» → «Получить ключ») и вставьте его в «Настройки → Модели»
     (или в `.env`: `GIGACHAT_CREDENTIALS=ваш_ключ`).
   - **Gemini.** Получите бесплатный ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
     и вставьте его в «Настройки → Модели» (или в `.env`: `GEMINI_API_KEY=ваш_ключ`). Если Gemini
     недоступен в вашем регионе, укажите там же прокси или включите VPN.
5. **Запустите `run.bat`.** Пока загружаются голосовые модели, ядро на экране вращается с надписью
   «Загрузка…»; текстом можно писать сразу. Если что-то не работает — запустите `check.bat`
   (см. «Диагностика»).

Ручная установка (вместо `install.bat`):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python download_models.py
copy .env.example .env
python main.py
```

## Как пользоваться

| Действие | Как |
|---|---|
| Сказать команду | «**Джарвис**, открой браузер» — режим «Джарвис» включён по умолчанию. Можно сказать просто «Джарвис», дождаться сигнала и произнести команду |
| Команда без слова «Джарвис» | Кнопка **«Микрофон»** или **Ctrl+Alt+J** (работает и при свёрнутом окне), после сигнала говорите |
| Написать команду | Поле ввода внизу, **Enter** или «Отправить». Под ядром — кнопки-примеры |
| Остановить речь и ответ | Кнопка **«Стоп»**, клавиша **Esc** или голосом: «стоп», «хватит», «Джарвис, замолчи» |
| Перебить | Скажите новую команду со словом «Джарвис», пока он говорит |
| Выключить озвучку | Переключатель «Озвучивать ответы» |
| Сменить модель | Переключатель **Ollama / GigaChat / Gemini / Qwen** вверху окна |
| Начать заново | «Новый диалог»: история очищается (иначе разговор продолжается и после перезапуска) |
| Ответить на предложение Джарвиса | Кнопки **«Да» / «Не сейчас» / «Не предлагать»** в карточке или голосом «да» / «нет» сразу после вопроса |
| Чтобы не отвлекал | Переключатель **«Не беспокоить»** слева: никаких предложений и брифингов |
| Микрофон, голос, ключи, проверка | Кнопка **«Настройки»** |

Слева — **ядро-индикатор** и его состояние: **Жду** (серый), **Слушаю** (синий), **Думаю**
(жёлтый), **Выполняю** (фиолетовый), **Говорю** (зелёный). Под ним полоса уровня звука — по ней
видно, слышит ли вас микрофон, и строка с тем, что сейчас распознаётся. Справа, в **журнале
действий**, — время, вызванный инструмент, его аргументы и результат.

Примеры команд:

- «Джарвис, открой браузер» / «открой телеграм» / «закрой блокнот»
- «Найди в интернете рецепт борща» / «Открой ютуб»
- «Сделай громкость 30» / «Погромче» / «Выключи звук» / «Следующий трек» / «Пауза»
- «Открой загрузки» / «Что лежит на рабочем столе?» / «Создай папку Проекты на рабочем столе»
- «Сделай скриншот» / «Какая загрузка процессора?» / «Открой настройки блютуз» / «Яркость 70»
- «Поставь таймер на 10 минут на чай» / «Запиши заметку: купить молоко»
- «Открой блокнот и напиши: привет, мир» / «Нажми ctrl+s»
- «Заблокируй компьютер» / «Выключи компьютер» (спросит подтверждение) / «Отмени выключение»
- «Какая погода завтра?» / «Сколько будет 2500 умножить на 1,15?» / «Напомни в 18:30 позвонить маме»
- «Переключись на браузер» / «Сверни телеграм» / «Найди файл отчёт» / «Скопируй это в буфер»

### Программирование

Попросите: «Джарвис, напиши программу, которая…». Код сохраняется в файл (просто имя — в папку
`Документы\Jarvis\Code`) и открывается в редакторе: VS Code, Cursor или Notepad++, если они
установлены, иначе Блокнот (свой редактор — `tools.code_editor`). Вслух код не зачитывается, а если
модель покажет пример прямо в чате, он будет в отдельном блоке с кнопкой «Копировать».
Программы на Python Джарвис запускает инструментом `run_python` и видит их вывод и ошибки, поэтому
может сам исправить код. **Каждый запуск вы подтверждаете**, видя код целиком; игры и программы с
окном открываются в отдельном окне. Перезапись существующего файла и запись вне вашей папки
пользователя тоже требуют подтверждения. Для кода лучше подходят облачные модели (Qwen, Gemini) или
`qwen3:8b` и крупнее.

### Память, сценарии и навыки

- **Память.** «Запомни, что…» — факт сохраняется навсегда и подмешивается в каждый запрос к модели
  («любимый браузер — Firefox», «город — Казань»). Посмотреть и поправить — «Настройки → Память».
  Разговор тоже сохраняется: после перезапуска Джарвис помнит, о чём шла речь («Новый диалог» — начать
  с чистого листа).
- **Контекст.** Модель знает заголовок активного окна, поэтому понимает «что тут?», «закрой это».
  Выделенный текст Джарвис берёт сам (как Ctrl+C, буфер обмена потом восстанавливается):
  «переведи выделенное», «исправь это».
- **Сценарии** — цепочки действий: «запомни как сценарий „кино“: громкость 70, открой ютуб и разверни
  браузер». Запуск — фразой «кино» или «запусти сценарий кино»: шаги выполняются сразу, без обращения
  к модели, поэтому мгновенно и бесплатно. Сценарии не запускают другие сценарии, опасные шаги
  по-прежнему спрашивают подтверждение.
- **Расписание** — сценарий или просьба по времени: «каждый будний день в 9:00 включай рабочий режим»,
  «каждые 30 минут напоминай размяться». Выполненное по расписанию попадает в чат и журнал;
  разовые напоминания — по-прежнему таймером.
- **Навыки** — то, чему Джарвис научился: папка с `SKILL.md` (описание и инструкции, формат
  [agentskills.io](https://agentskills.io)) и, если нужно, `script.py`. «Сохрани это как навык» —
  в следующий раз модель найдёт навык по описанию. **Скрипт навыка вы подтверждаете, видя код,**
  при сохранении и после каждого изменения; одобренный скрипт запускается без вопросов.
- **Откат.** `write_file` сохраняет прежнюю версию файла в `Backups` — «верни файл как было» откатывает
  последнее изменение (текущая версия тоже сохраняется).

Всё это лежит в `Документы\Jarvis` (`memory.json`, `history.json`, `routines.json`, `schedule.json`,
`Skills\`, `Backups\`; своя папка — `paths.data`), поэтому не пропадает при обновлении программы.

### Зрение

Инструмент `screen` делает снимок экрана и отправляет его модели со зрением: она отвечает на вопрос
(«что за ошибка на экране?») или находит элемент по описанию, чтобы на него нажать. **Перед кликом
показывается снимок с красной отметкой места**, и нужно нажать «Да» (`tools.confirm_clicks`). Видят
Qwen и Gemini; для Ollama нужна модель со зрением: `ollama pull qwen2.5vl:7b` и `ollama.vision_model`.
Если текущая модель не видит, Джарвис сам возьмёт Qwen или Gemini, когда для них есть ключ
(`vision.backend`). Снимок уходит в облако только в момент вызова `screen`.

### Сам предлагает помощь

Раз в 10 минут Джарвис без обращения к модели (это бесплатно) проверяет диск, батарею, память и
процессор. Если что-то не так — карточка с вопросом и голос: «Сэр, на диске C: осталось 3 ГБ. Показать,
что занимает место?». Ответ — кнопкой или голосом «да» / «нет».

- Не больше двух предложений в час (`proactive.max_per_hour`), одно и то же — не чаще раза в 6 часов,
  ничего в тихие часы (23:00–08:00) и в режиме «Не беспокоить».
- «Не сейчас» — пауза на сутки, после трёх отказов подряд такие предложения затихают на неделю,
  «Не предлагать» — навсегда (вернуть: «Настройки → Память → Снова предлагать всё»).
- **Утренний брифинг** — при первом появлении за компьютером с 5 до 12 часов: дата, погода, напоминания
  и расписание на сегодня, состояние ПК. Город берётся из настроек или памяти («мой город — Казань»).
  Голосом — «доброе утро» или «брифинг».
- **«Пока вас не было»** — если вы отходили больше чем на 15 минут, а за это время сработали таймеры
  или расписание, Джарвис покажет сводку, а отложенные предложения — когда вернётесь.
- **HUD** — когда окно Джарвиса свёрнуто, в правом верхнем углу появляется мини-индикатор: «слушаю»,
  «думаю», какой инструмент выполняется. Щелчок по нему открывает окно (`ui.hud`).

### Окно «Настройки»

- **Голос** — выбор микрофона, чувствительность (усиление тихого микрофона), кнопка
  **«Проверить микрофон»** (запись 4 секунды: громкость и что распознано), голос Джарвиса с
  прослушиванием, варианты слова-активатора, звуковой сигнал.
- **Доступ к ПК** — список инструментов модели, переключатели **команд PowerShell** и **запуска кода
  Python**, безопасная проверка инструментов.
- **Модели** — модели и ключи API для Qwen, GigaChat, Gemini, адрес Ollama, прокси для Gemini.
  Ключи сохраняются в файл `.env`.
- **Память** — что Джарвис о вас помнит (можно править), сохранение разговора, учёт активного окна,
  список сценариев, расписания и навыков, предложения помощи, брифинг, город для погоды, тихие часы, HUD.
- **Диагностика** — полная проверка (см. ниже).

Всё, что меняется в окне, запоминается в `user_settings.json` (он важнее `config.yaml`; удалите
его, чтобы вернуть настройки по умолчанию).

## Инструменты

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `open_app(name)` | Запуск по алиасу из `config.yaml` («браузер», «блокнот», «калькулятор», «проводник», «телеграм»…), иначе поиск ярлыка в меню «Пуск» (включая приложения Microsoft Store) | — |
| `close_app(name, force)` | Закрывает приложение: сначала как «крестик» (программа сама спросит о сохранении), `force=true` завершает принудительно (psutil) | **да** |
| `open_url(url)` / `web_search(query)` | Сайт или поиск в браузере по умолчанию (только http/https) | — |
| `open_folder(path)` | «Загрузки», «Документы», «Рабочий стол», «Изображения», «Музыка», «Видео», «Корзина», вложенные и полные пути | — |
| `create_folder(path)` / `list_folder(path)` | Создать папку (просто имя — на рабочем столе) / показать её содержимое | — |
| `set_volume(level)` / `change_volume(delta)` / `mute(on)` | Громкость 0–100, «погромче/потише», режим «без звука» (pycaw) | — |
| `set_brightness(level)` | Яркость экрана (ноутбуки и мониторы с поддержкой) | — |
| `open_settings(page)` | Раздел параметров Windows: экран, звук, Bluetooth, Wi-Fi, обновления, обои… | — |
| `media(action)` | `play_pause`, `next`, `previous`: медиаклавиши | — |
| `type_text(text)` | Печатает текст в активном окне (русский тоже, независимо от раскладки) | — |
| `hotkey(keys)` | Сочетание клавиш через pyautogui, например `ctrl+c`, `win+d` | **только Alt+F4** |
| `screenshot()` | Снимок всех экранов в «Изображения\Jarvis» | — |
| `system_info()` | Процессор, память, батарея, диск, время работы | — |
| `get_datetime()` | Дата, время, день недели | — |
| `timer(minutes / at, label)` | Таймер или напоминание на время «ЧЧ:ММ»; по окончании — уведомление Windows и голос | — |
| `note(text)` | Дописывает заметку в «Документы\Jarvis\notes.txt» | — |
| `write_file(path, content)` | Сохраняет код или текст в файл и открывает в редакторе | **при перезаписи или записи вне папки пользователя** |

## Безопасность

- `close_app`, `sleep_pc`, `shutdown_pc`, `restart_pc`, `run_powershell`, `run_python`, `hotkey` с Alt+F4,
  перезапись файлов, клик по экрану и новый скрипт навыка выполняются **только после подтверждения** в диалоге
  с точным описанием действия и кнопками «Да, выполнить» / «Нет». Если ответа нет 20 секунд (`tools.confirm_timeout`), действие отменяется.
  Подтвердить можно только кнопкой, голосом нельзя, чтобы случайная фраза ничего не выключила.
- Проверку делает реестр инструментов до вызова функции, так что обойти её из модели нельзя.
- `run_powershell` выключен по умолчанию, а при включении всегда показывает команду целиком.
- Модель может вызвать только инструменты из списка, неизвестные вызовы отклоняются.
- Ошибка инструмента не роняет программу: её текст возвращается модели, а та сообщает о проблеме.
- `close_app` не трогает системные процессы и сам Джарвис. «Проводник» закрывает только окна,
  а не процесс `explorer.exe`.
- Alt+F4 никогда не отправляется в окно Джарвиса: в диалоге подтверждения видно, какое окно закроется.
- Бесплатная модель Qwen не переходит на платные запросы, когда дневной лимит исчерпан
  (`qwen.free_fallback: false`).
- Сценарии и расписание состоят только из существующих инструментов, а опасные шаги в них спрашивают
  подтверждение так же, как при обычной просьбе. Предложения Джарвиса без вашего «да» ничего не делают.
- Перед перезаписью файла Джарвис сохраняет прежнюю версию, так что правку можно откатить.
- Запись макросов (всех нажатий клавиш и мыши) намеренно не сделана: это работает как кейлоггер и
  ломается от любого сдвига окна. Вместо неё — сценарии из инструментов.

## Диагностика

**«Настройки → Диагностика → Запустить диагностику»** или **`check.bat`** (то же самое:
`python main.py --check`) проверяют по шагам: библиотеки, список микрофонов, запись с микрофона
(скажите «Джарвис, проверка связи»), распознавание слова «Джарвис», синтез речи, связь с моделью
и инструменты управления ПК. Отчёт сохраняется в `logs\diagnostics.txt` — его удобно приложить
к вопросу. Подробный лог работы — `logs\jarvis.log`.

## Решение проблем

Ошибки и подсказки по исправлению показываются прямо в чате.

**Голос**

- **Джарвис не слышит, полоса уровня под ядром не шевелится, в чате «микрофон передаёт полную
  тишину»** — Windows не даёт программе доступ к микрофону. Откройте «Параметры → Конфиденциальность
  и защита → Микрофон» и включите «Доступ к микрофону» и «Разрешить классическим приложениям доступ
  к микрофону». Проверьте, не выключен ли микрофон кнопкой.
- **Слышит не тот микрофон** — выберите нужный в «Настройки → Голос» и нажмите «Проверить микрофон».
- **Полоса уровня еле заметна, команды не распознаются** — говорите ближе или увеличьте
  «Чувствительность» в «Настройки → Голос».
- **Не реагирует на «Джарвис»** — проверьте, что включён переключатель «Режим «Джарвис»». Под ядром
  видно, что распознаётся; если слово распознаётся иначе (например «джервис»), добавьте этот вариант
  в «Настройки → Голос → Слово-активатор».
- **Нет модели Vosk** — она скачивается сама при запуске; вручную: `python download_models.py --vosk`.
  Текстовый режим работает всегда.
- **Русские буквы в пути к папке** (например `C:\Users\Иван\…`) Джарвис обходит сам. Если модель Vosk всё же
  не загружается, перенесите папку с Джарвисом в путь без кириллицы, например `C:\Jarvis`.
- **Джарвис реагирует на свой голос** — используйте наушники или уменьшите громкость. Эхо фильтруется,
  но с громкими колонками возможны ложные срабатывания.

**Модели**

- **«Ollama не запущена»** — запустите приложение Ollama (значок в трее) или `ollama serve`.
- **«Модель qwen3:8b не найдена»** — `ollama pull qwen3:8b`.
- **Ollama отвечает медленно** — без видеокарты `qwen3:8b` работает медленно: попробуйте `qwen3:4b`
  или облачные Qwen/Gemini/GigaChat.
- **Qwen: «ключ недействителен (401)»** — проверьте ключ `sk-bl-…` в «Настройки → Модели → Qwen».
- **Qwen: «исчерпан бесплатный лимит»** — у `qwen/qwen3.7-flash:free` 10 запросов в минуту и 50 в день.
  Подождите или выберите `qwen/qwen3.7-flash` (нужен баланс на BazaarLink).
- **GigaChat: ошибка SSL-сертификата** — `python download_models.py --cert` (скачивает корневой
  сертификат НУЦ Минцифры и проверяет его отпечаток) или установите сертификат с
  [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt). Крайний вариант: `gigachat.verify_ssl_certs: false`.
- **GigaChat: 401** — проверьте ключ (целиком, без кавычек) и `scope: GIGACHAT_API_PERS`.
- **Gemini: «недоступен в вашем регионе»** — укажите прокси в «Настройки → Модели» или включите VPN.
- **Gemini: 429** — исчерпан бесплатный лимит, подождите или выберите `gemini-flash-lite-latest`.

**Скорость**

- Быстрее всего отвечают облачные модели (Qwen `qwen/qwen3.7-flash:free`, Gemini Flash). Локальной
  модели без видеокарты нужно несколько секунд на ответ; если `qwen3:8b` слишком медленная —
  `ollama pull qwen3:4b` и выберите её в «Настройки → Модели».
- Простые команды («открой», «громче», «пауза») выполняются за один запрос к модели (`llm.fast_replies`).
- Длинные старые результаты (например, код из прошлых ответов) в истории сокращаются, чтобы запрос
  к модели оставался коротким.

**Прочее**

- **Модель отвечает, что не может управлять компьютером** — посмотрите «Настройки → Доступ к ПК»:
  там список инструментов, а «Проверить инструменты» показывает, что они работают. Маленькие локальные
  модели иногда ошибаются — попробуйте Qwen, Gemini или GigaChat-2-Max.
- **Горячая клавиша не работает** — сочетание занято другой программой: смените `hotkey` в `config.yaml`.
- **«Нет модели, которая умеет смотреть на экран»** — выберите Qwen или Gemini (или добавьте их ключ)
  либо скачайте для Ollama модель со зрением: `ollama pull qwen2.5vl:7b` и `ollama.vision_model`.
- **Джарвис предлагает лишнее** — ответьте «Не предлагать», включите «Не беспокоить» или выключите
  предложения в «Настройки → Память».
- **Брифинг называет не тот город** — впишите город в «Настройки → Память → Город для погоды».
- **Консоль не нужна** — запускайте `.venv\Scripts\pythonw.exe main.py` (или ярлык на него).

## Как это устроено

```
main.py                   запуск, логирование, --check (диагностика)
config.yaml, .env         настройки и ключи; user_settings.json — изменения из окна
download_models.py        скачивание моделей Vosk/Silero и сертификата GigaChat
jarvis/
  app.py                  контроллер: связывает окно, агента, голос, горячую клавишу
  ui/                     окно CustomTkinter: тема, иконки, ядро-индикатор, чат, журнал, диалоги, HUD
  agent.py                агентский цикл: модель → инструменты → результат → ответ; сценарии без модели
  llm/                    бэкенды за общим интерфейсом: ollama, gigachat, gemini, qwen
  tools.py                инструменты управления ПК с JSON-схемами и подтверждениями
  winapi.py               WinAPI через ctypes: окна, фокус, ввод, папки, уведомления
  stt.py                  распознавание речи Vosk: выбор микрофона, уровень, слово-активатор
  tts.py                  синтез Silero и очередь воспроизведения
  diagnostics.py          проверка всех частей и отчёт
  memory.py, storage.py   память о пользователе и история диалога в «Документы\Jarvis»
  routines.py             сценарии, расписание и планировщик
  skills.py, backups.py   навыки (agentskills.io) и резервные копии файлов
  proactive.py            heartbeat: проверки ПК, предложения, лимиты, «пока вас не было»
  briefing.py             утренний брифинг
  vision.py               снимок экрана → модель со зрением → ответ или координаты клика
  text_utils.py           подготовка текста к озвучке, предложения, слово-активатор
  hotkey.py               глобальная горячая клавиша (RegisterHotKey)
tests/                    автотесты (pytest); tests/windows — проверки на настоящей Windows
```

- **Потоки.** Окно работает в главном потоке. Модель и инструменты, микрофон, синтез, воспроизведение
  и горячая клавиша живут в фоновых потоках и общаются с окном через очередь и `after()`,
  поэтому интерфейс не зависает.
- **Агентский цикл:** не больше 5 обращений к модели на запрос (10 — когда модель пишет и запускает код).
  На последнем шаге модель обязана ответить текстом. В контекст идут последние 20 сообщений, факты из
  памяти, список сценариев и навыков; активное окно добавляется к текущей реплике, а не к системному
  промпту, чтобы локальная модель не пересчитывала его заново.
- **Ответ** выводится в чат по мере генерации и озвучивается по предложениям: следующее предложение
  синтезируется, пока играет предыдущее. Перед синтезом текст очищается от markdown и эмодзи,
  числа переводятся в слова с согласованием («двадцать одна минута», «из шестнадцати гигабайт»),
  латиница читается по-русски, текст режется на куски до 800 символов.
- **Слово «Джарвис»** узнаётся уже по промежуточным результатам распознавания — индикатор
  переходит в «Слушаю», пока вы договариваете команду.
- **Vosk и Silero** загружаются один раз при старте и скачиваются автоматически, если файлов нет.

### Добавить свой инструмент

```python
# jarvis/tools.py
@tool(
    "open_calendar",
    "Открыть календарь Windows.",
    {"date": {"type": "string", "description": "Дата в формате ДД.ММ.ГГГГ (необязательно)"}},
)
def open_calendar(ctx: CallContext, date: str = "") -> str:
    os.startfile("outlookcal:")
    return "Календарь открыт."
```

Опасному действию добавьте `confirm=функция`, возвращающую `Confirmation(...)`: тогда реестр
не вызовет инструмент без нажатия «Да».

### Тесты

```bat
.venv\Scripts\python -m pip install pytest
.venv\Scripts\python -m pytest
```

Обычные тесты не требуют Windows, сети и моделей: они проверяют нормализацию текста, слово-активатор,
микрофон и распознавание (без звука), реестр инструментов и подтверждения, агентский цикл, форматы
